# DND 5R 自动车卡

基于 React + Vite + TypeScript 的 DND 5R（2024 修订版规则）单页自动车卡工具。
所有规则数据**实时拉取**自 [DND5eChm/DND5e_chm](https://github.com/DND5eChm/DND5e_chm)（《5E不全书》）仓库，
跟随仓库更新自动失效缓存，无需后端。

## 运行

```bash
npm install
npm run dev      # 开发：http://localhost:5180
npm run build    # 生产构建到 dist/
```

## 数据来源：「本书速查」

应用不抓取单一书目，而是解析仓库根部的 `不全书.wcp`（WinCHM 工程文件，UTF-16），
其中「本书速查」章节就是覆盖全部已翻译扩展的聚合目录树：

| 速查章节 | 提供内容 |
| --- | --- |
| 职业速查 | 17 个职业（PHB2024 ×12、奇械师 EFA、第三方 ×4），每个职业下挂全部书目的子职（XGE/TCE/SCAG/FR/第三方…） |
| 起源速查 · 种族 | 130+ 个种族，按来源书分组（PHB2024/MPMM/AAG/EGW/第三方…） |
| 起源速查 · 2024背景 | 69 个 2024 格式背景（PHB24/FR/EFA/歪曲之月…） |
| 法术速查 | 9 个施法职业的全书法术列表（每职业 300+ 法术，含学派/环阶/来源） |

### 拉取流程

1. `GET /branches/main` 取最新 commit SHA（每次打开都会检查，保证实时）；
2. SHA 未变 → 直接使用 localStorage 缓存的索引/实体；
3. SHA 变化或强制刷新 → 重新下载 `不全书.wcp` 解析目录树索引；
4. 选中具体职业/子职/种族/背景/法术列表时，按需拉取对应 htm 页面
   （GBK/GB18030 自动解码），解析结果按 SHA 缓存。

GitHub API 仅用 1 次调用/加载，页面均走 raw.githubusercontent.com，不易触发限流。

## 车卡流程（2024 规则）

1. **选择职业**：自动解析核心特质表（生命骰、豁免、技能选择数、起始装备 A/B/C）
   与逐级特性表（含法术位/戏法数/准备法术数，魔契师契约法术位单独处理）；
2. **确定起源**：种族给体型/速度/特质（旧版种族按 2024 规则忽略其属性值提升；
   特质中授予的技能熟练会自动计入），背景给三选项属性加值（+2/+1 或三项各 +1）、
   起源专长、技能与工具熟练；
3. **确定属性值**：标准数组 / 27 点购点 / 4d6 去最低投骰，
   「按职业自动分配」一键把最高值给主属性、次高给体质，并同步指定背景加值；
4. **护甲与武器**：按装备表自动计算 AC，武器自动生成攻击动作（灵巧/远程自动选属性）；
5. **法术**：从法术速查勾选（支持搜索/按环阶折叠），法术位、豁免 DC、攻击加值自动计算。

右侧实时渲染角色卡（怪物图鉴风格），并可复制/下载符合 **E5StatblockIn** JSON Schema
的角色数据（`src/types.ts` 中的 `E5Statblock` 与 schema 一一对应）。

## 代码结构

```
src/
  types.ts              E5StatblockIn 类型 + 解析数据类型 + 用户选择状态
  data/
    github.ts           GitHub 拉取层（分支信息 / wcp / 页面，GBK 解码，SHA 缓存）
    toc.ts              不全书.wcp 目录树解析 →「本书速查」索引
    parsers.ts          htm 页面解析（职业核心表/特性表、种族、背景、子职、法术列表）
    loader.ts           编排：索引加载 + 实体按需加载
    mappings.ts         属性/技能/体型 中英映射（含旧译名别名）
  rules/
    rules.ts            规则常量：标准数组、购点、护甲表、武器表、HP/PB 计算
    build.ts            用户选择 + 解析数据 → E5StatblockIn 角色卡
  components/
    panels.tsx          左侧车卡步骤面板
    sheet.tsx           右侧角色卡预览 + JSON 导出
```

## 已知限制

- 2014 老排版页面（Word 导出 HTML）解析尽力而为，个别种族特质可能不全，可在备注中补充；
- 专长只记录名称（来自背景），专长详情页暂未解析；
- 兼职（multiclass）暂不支持。
